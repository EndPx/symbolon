# Overview

These guides explain how to use the public Symbolon app. Begin with your HackCanton account and test assets, then choose the activity you want to perform.

| Guide | Use it when you want to… |
| --- | --- |
| [Getting Started](public-devnet.md) | Connect an account, choose a party and obtain test assets. |
| [Borrowers](borrower.md) | Request financing, compare offers and recover collateral through repayment. |
| [Lenders](dealer-oracle.md) | Register for a market, price requests and fund an offer. |
| [Troubleshooting](troubleshooting.md) | Resolve an empty directory, expired price or incompatible balance. |

For quick answers and definitions, open [FAQ](faq.md) or [Glossary](../reference/glossary.md) under **Other**.

## Example: which guide should I choose?

If Alex has collateral and needs 1,000 cash, follow Borrowers. If Blair has cash and wants to price Alex's request, follow Lenders. The same authorized party can perform either activity in separate agreements.

Borrow and Lend change the activity shown. They do not change the signing party. If rehearsing both counterparties in one test account, choose the borrower or lender under **Account → Advanced account controls → Authorized account party**.

Local setup commands and complete developer demonstrations are kept in the [source repository](https://github.com/EndPx/symbolon). You do not need to install a local ledger to use the published app.
